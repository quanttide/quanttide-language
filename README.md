# quanttide-language

量潮语言分析

## 概述

quanttide-language 是量潮语言分析领域，围绕语言的结构、意义与用法，沉淀领域第二大脑。

## 领域边界

- **语言结构**：词汇、句法、篇章的组织规律
- **语义与语用**：意义识别、指代消解、歧义与隐含意图
- **文体与风格**：章程、手册、教程、宣传等不同文体的语言特征与写作规范
- **语言数据**：语料、词表、标注与可度量的语言指标
